# 📋 手動オペレーション・チェックリスト (MANUAL_TASKS.md)

[English](MANUAL_TASKS.md) | [简体中文](MANUAL_TASKS.zh-CN.md)

> [!NOTE]
> 本ドキュメントは、開発およびリリース過程において**人間のエンジニアによる外部設定や手動実行が必要な作業**（サードパーティ製クラウドコンソール、決済ゲートウェイ、アプリストアの証明書、本番シークレットの設定、実機検証など）を追跡・記録します。
> AI エージェントが外部コンソールでの操作を「完了した」と勝手に偽ることは固く禁じられています。このようなタスクが発生した場合は、ここに `[ ]` チェックボックス形式で登録し、ユーザーに通知してください。

---

## 1. 🔑 外部クラウドサービスおよび認証情報の設定

- [ ] **1.1 クラウドデータベース / バックエンドサービス (例: Supabase / Firebase / AWS)**
  - [ ] コンソールにログインし、本番プロジェクトを作成・連携する
  - [ ] クライアント公開キーとサーバー管理者シークレットを取得する
  - [ ] コンソールで CORS 許可オリジンおよびリダイレクト URL を設定する

- [ ] **1.2 セキュリティ・不正防止 (例: Cloudflare Turnstile / Captcha)**
  - [ ] サイトキー（公開）とシークレットキー（非公開）を発行する
  - [ ] ローカルデバッグ用ドメイン（`localhost` / `127.0.0.1`）を登録する

- [ ] **1.3 決済およびサブスクリプション (例: Stripe / Apple In-App Purchase)**
  - [ ] 管理画面で商品と料金プラン（Price ID / Product ID）を作成する
  - [ ] Webhook エンドポイントを登録し、署名シークレットを保存する

---

## 2. 🚀 本番環境へのデプロイとデータベース移行

- [ ] **2.1 本番データベースの増分マイグレーション実行**
  - 移行コマンドを実行する（例: `supabase db push` / `npx prisma migrate deploy`）
  - テーブルロックや後方互換性の問題をログで確認する

- [ ] **2.2 本番環境変数の登録**
  - ホスティング環境（Vercel / Cloudflare Pages / AWS）に必要な本番シークレットを設定する

---

## 3. 📱 モバイルおよび配信コンソール（該当する場合）

- [ ] **3.1 Apple Developer & App Store Connect**
  - [ ] App ID の作成、Capabilities（Push 通知、Sign in with Apple 等）の設定
  - [ ] アプリ内課金アイテムの登録と審査用情報の入力
  - [ ] App Store Server Notifications V2 のエンドポイント設定

---

## 4. 🧪 実機検証およびエンドツーエンドテスト

- [ ] **4.1 物理実機での動作確認**
  - [ ] カメラ、マイク、Bluetooth、Push 通知のパーミッションダイアログ動作確認
  - [ ] オフラインや低速ネットワーク環境下での適切なフォールバック処理の検証
